=================================================================
  ODONTOGEST — GUÍA DE INSTALACIÓN Y EJECUCIÓN
  Backend: FastAPI + Python | Frontend: React + Vite + TypeScript
=================================================================

REQUISITOS
----------
- Python 3.10 o superior
- Node.js 18 o superior (incluye npm)
- PostgreSQL (o SQLite para desarrollo)
- Git

─────────────────────────────────────────────────────────────────
1. CLONAR EL REPOSITORIO
─────────────────────────────────────────────────────────────────

  git clone <url-del-repositorio>
  cd Dental-Appointment-System

─────────────────────────────────────────────────────────────────
2. BACKEND — ENTORNO VIRTUAL Y DEPENDENCIAS
─────────────────────────────────────────────────────────────────

  # Crear entorno virtual
  python -m venv venv

  # Activar (Windows PowerShell)
  .\venv\Scripts\Activate.ps1

  # Si da error de permisos, ejecutar primero:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

  # Instalar dependencias
  pip install -r requirements.txt

  # Salir del entorno virtual cuando termines:
  deactivate

─────────────────────────────────────────────────────────────────
3. BASE DE DATOS
─────────────────────────────────────────────────────────────────

  Opción A — PostgreSQL (producción)
  ───────────────────────────────────
  1. Crear base de datos llamada "odontogest" en PostgreSQL
  2. Copiar .env.example como .env y editar DATABASE_URL:
     DATABASE_URL=postgresql://usuario:password@localhost:5432/odontogest

  Opción B — SQLite (desarrollo rápido)
  ──────────────────────────────────────
  1. En el archivo .env poner:
     DATABASE_URL=sqlite:///./odontogest.db

  Crear las tablas (ambas opciones):
  .\venv\Scripts\python crear_tablas.py

  ¡Importante! Esto crea 8 tablas:
  - pacientes     - doctores      - turnos
  - pagos         - historias_clinicas
  - turnos_tratamientos  - cuentas_corrientes  - movimientos_cuenta

─────────────────────────────────────────────────────────────────
4. EJECUTAR BACKEND
─────────────────────────────────────────────────────────────────

  # Activar venv (si no está activo)
  .\venv\Scripts\Activate.ps1

  # Iniciar servidor FastAPI (puerto 8000)
  uvicorn backend.main:app --reload

  # Abrir en el navegador:
  Swagger UI:  http://127.0.0.1:8000/docs
  API base:    http://127.0.0.1:8000

  Para detener: Ctrl + C

─────────────────────────────────────────────────────────────────
5. FRONTEND — INSTALAR DEPENDENCIAS
─────────────────────────────────────────────────────────────────

  # Ir a la carpeta frontend
  cd frontend

  # Instalar dependencias (una sola vez)
  npm install

  # Volver a la raíz
  cd ..

─────────────────────────────────────────────────────────────────
6. EJECUTAR FRONTEND (EN OTRA TERMINAL)
─────────────────────────────────────────────────────────────────

  # Terminal 2 — desde la carpeta raíz
  cd frontend
  npm run dev

  # Abrir en el navegador:
  http://localhost:5173

  El frontend usa un proxy que redirige /api/* a http://localhost:8000
  así que no hay que configurar CORS manualmente.

  Para detener: Ctrl + C

─────────────────────────────────────────────────────────────────
7. FLUJO COMPLETO (DOS TERMINALES)
─────────────────────────────────────────────────────────────────

  Terminal 1 — Backend:
  ──────────────────────
  cd D:\....\Dental-Appointment-System
  .\venv\Scripts\Activate.ps1
  uvicorn backend.main:app --reload

  Terminal 2 — Frontend:
  ──────────────────────
  cd D:\....\Dental-Appointment-System\frontend
  npm run dev

─────────────────────────────────────────────────────────────────
8. PRIMEROS PASOS EN LA APP
─────────────────────────────────────────────────────────────────

  1. Crear al menos 1 doctor desde Swagger:
     POST http://127.0.0.1:8000/doctores/
     Body: {"nombre": "Darío", "color_agenda": "#0061a4"}

  2. Crear otro doctor:
     POST {"nombre": "Fabiana", "color_agenda": "#7c3aed"}

  3. Ir al frontend http://localhost:5173 y usar la app

─────────────────────────────────────────────────────────────────
9. COMANDOS RÁPIDOS (RESUMEN)
─────────────────────────────────────────────────────────────────

  BACKEND:
  .\venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  python crear_tablas.py
  uvicorn backend.main:app --reload

  FRONTEND:
  cd frontend
  npm install
  npm run dev

  BUILD PRODUCCIÓN:
  cd frontend
  npm run build    # genera frontend/dist/

─────────────────────────────────────────────────────────────────
